# 色彩规范：功能色渐变

## 使用说明

功能色渐变不用适配品牌色换肤功能，属于固定样式。下方列举的是常用固定渐变，主要用于指标卡重色状态、多指标卡选中状态，以及未选中状态。

## 固定渐变 Token

| 名称 | Token | 渐变色值 | 用途 |
|---|---|---|---|
| Color/渐变/Dark/Red_01 | `color-gradient-red-01` | `linear-gradient(0% #F68052 -> 43% #FF9A64 -> 100% #FFBE8E)` | 指标卡重色、多指标卡选中状态 |
| Color/渐变/Dark/Purple_01 | `color-gradient-purple-01` | `linear-gradient(0% #4C67FF -> 100% #ACB5FF)` | 指标卡重色、多指标卡选中状态 |
| Color/渐变/Dark/Yellow_01 | `color-gradient-yellow-01` | `linear-gradient(0% #FE7400 -> 100% #FFCA42)` | 指标卡重色、多指标卡选中状态 |
| Color/渐变/Dark/Blue_01 | `color-gradient-blue-01` | `linear-gradient(0% #027FFF -> 100% #7ABBFF)` | 指标卡重色、多指标卡选中状态 |
| Color/渐变/Dark/Green_01 | `color-gradient-green-01` | `linear-gradient(0% #0EAC8E -> 100% #3DE7A0)` | 指标卡重色、多指标卡选中状态 |
| Color/渐变/Dark/Grey_01 | `color-gradient-grey-01` | `linear-gradient(0% #F7F8FA -> 59% #F2F3F5 -> 100% #E5E6EC)` | 指标卡重色、未选中状态 |

## 示例卡片装饰渐变

Figma 示例卡片中还出现一组右侧装饰渐变，适用于指标卡内部的固定高光形状：

| 用途 | 渐变色值 |
|---|---|
| 选中指标卡内部装饰 | `linear-gradient(0% #FF6B2F -> 43% #FE894A -> 96% #FFB95C)` |
| 默认/未选中指标卡内部装饰 | `linear-gradient(0% #F7F8FA -> 59% #F2F3F5 -> 100% #E5E6EC)` |

## 投影

| 类型 | 规则 |
|---|---|
| 功能色渐变投影 | 使用固定功能色渐变，不参与品牌换肤 |
| 品牌色渐变投影 | 回到品牌色规则，取品牌色 35% 透明度 |

## 落地规则

- 需要随品牌变化的组件，不使用本页固定功能色渐变。
- 指标卡选中态可用 Red、Purple、Yellow、Blue、Green 五组重色渐变。
- 未选中态或弱强调指标卡使用 Grey 渐变。
- 功能色渐变的命名保留 `color-gradient-{color}-01` 结构，避免与品牌色渐变 `color-gradient-primary-*` 混用。
