## 1. Visual Theme & Atmosphere

蝉圈圈 Web 端组件库整体是偏业务系统与增长分析产品的视觉语言：干净、轻量、数据友好，使用大量浅灰背景承载表格、筛选、卡片和数据模块，再用温暖的珊瑚橙品牌色建立行动焦点。

视觉气质应避免厚重的营销页装饰感。系统页面优先表现为“清晰的运营工作台”：白色内容面、浅灰框架背景、低对比边框、清楚的文字层级，以及少量高饱和功能色用于状态、指标和图表。

使用本规范时优先遵循这几个判断：

- 业务主操作、选中态、品牌强调统一回到品牌主色 `#FF7752`。
- 信息层级主要由中性灰完成，不用临时透明黑或随意调暗。
- 数据卡、指标卡和图表可以使用蓝、绿、橙、红、紫、蔚蓝作为辅助色，但它们不替代品牌主色。
- 大面积页面背景保持轻、平、克制，强调色只用于需要用户注意或行动的位置。

文字颜色建议：

- 页面标题、卡片主标题：`color-gray-default-primary` / `#1D2129`。
- 正文、副标题、筛选默认文案：`color-gray-default-08` / `#4E5969`。
- 表头标题、注释、说明、辅助信息：`color-gray-default-06` / `#86909C`。
- 禁用状态：`color-gray-default-05` / `#A9AEB8`。
- 反色文字：`color-basic-white-default` / `#FFFFFF`。

## 4. Component Styles

以下组件规则用于补充组件语义、视觉规格和状态表现。若具体设计稿本身有更精确组件实例，应以该实例的尺寸、约束和组件属性为准；若缺少组件上下文，则按本节补齐。

### 4.1 按钮 Button

主按钮应是蝉圈圈界面里最明确的行动入口，默认使用品牌主色 `#FF7752`，文字用白色。Hover 使用 `#FF9275`，Click 使用 `#E56B4A`，禁用底色使用 `#FFD6CB`，加载或弱禁用可用 `#FFC9BA`。

按钮视觉应轻快、直接，不做过重阴影。系统界面内按钮圆角建议保持中等圆角，不使用胶囊形作为默认风格，除非设计稿组件本身明确是圆角胶囊。

推荐按钮类型：

| 类型 | 背景 | 文字 | 边框 | 使用场景 |
|---|---|---|---|---|
| Primary | `#FF7752` | `#FFFFFF` | 无或同背景 | 主操作、确认、提交 |
| Primary Hover | `#FF9275` | `#FFFFFF` | 无或同背景 | 悬浮态 |
| Primary Pressed | `#E56B4A` | `#FFFFFF` | 无或同背景 | 点击态 |
| Primary Disabled | `#FFD6CB` | `#FFFFFF` 或 `#A9AEB8` | 无 | 禁用态 |
| Secondary | `#FFFFFF` | `#1D2129` 或 `#4E5969` | `#E5E6EC` | 次操作、取消、筛选 |
| Text Button | 透明 | `#FF7752` | 无 | 链接、轻量操作 |
| Dark Emphasis | `#1D2129` | `#FFFFFF` | 无 | 少量强强调按钮、标签选中状态 |

Button 组件实例补充规范来自 Figma 节点 `1:23` / Button 组件集。具体 Button 组件应优先遵循组件实例属性；以下规则用于缺少组件上下文时补齐。

按钮尺寸体系：

| 尺寸 | 高度 | 常见文字 | 行高 | 常见横向 Padding | icon 尺寸 | icon/text 间距 |
|---|---:|---:|---:|---:|---:|---:|
| 超大 | 40px | 16px | 24px | 20px | 16px | 6px |
| 大 | 36px | 14px | 22px | 14px | 16px | 6px |
| 默认 | 32px | 14px | 22px | 14px | 16px | 6px |
| 小 | 28px | 14px | 22px | 14px | 16px | 6px |
| 迷你 | 24px | 12px 或 14px | 16px / 22px | 14px | 16px | 6px |

矩形按钮和图标按钮默认圆角为 `6px`。图标按钮使用正方形尺寸：40 / 36 / 32 / 28 / 24px，对应相同高度规格。

Figma Button 组件样式包含：

- `01 主按钮-矩形`：品牌主色填充，白色文字。
- `02 描边主题色`：白底，品牌色边框与文字。
- `03 描边灰色`：白底，灰色边框，灰阶文字。
- `04 浅色填充`：品牌浅色背景，品牌色文字。
- `05 主按钮_可选择按钮`：用于左右分段或多段选择，存在左/右/全禁用/全加载状态。
- `06 文字按钮-中性色`：透明背景，中性文字。
- `07 虚线按钮-品牌色`：品牌色虚线描边。
- `08 文字按钮-品牌色`：透明背景，品牌色文字。
- `09 图标按钮-品牌色描边`：图标按钮，品牌色描边。
- `10 图标按钮-主色浅填充`：图标按钮，品牌浅色填充。
- `11 图标按钮-实色填充`：图标按钮，品牌主色实色填充。
- `12 图标按钮-描边-虚线`：图标按钮，虚线描边。
- `13 图标按钮-深色描边`：图标按钮，深色描边。
- `14 图标按钮-浅灰色填充`：图标按钮，浅灰底。

按钮状态全集：

| 状态 | 推荐规则 |
|---|---|
| 默认 | 使用对应样式的默认背景、文字、边框 |
| Hover | 主按钮用 `#FF9275`；描边/浅色/文字/图标按钮按同色系 Hover 变量或浅底反馈 |
| 点击 / Active | 主按钮用 `#E56B4A`；描边/浅色/文字/图标按钮按同色系点击变量或更深反馈 |
| 禁用 | 主按钮底色 `#FFD6CB`；文字或图标可用白色或 `#A9AEB8`，描边/文字按钮弱化到禁用灰 |
| 加载 | 主按钮底色 `#FFC9BA`，文字和 icon 保持弱禁用状态；需要 loading icon 时使用组件原始 icon |
| 可选择按钮左/右/全状态 | 保留 Figma 组件分段位置属性，不用普通按钮拼接近似 |

按钮变量别名需要兼容 Figma 中的命名：`Color/Primary/Default 品牌色、主色、默认色、强调色、New标签` = `#FF7752`，`Color/Primary/Light_09 状态-Hover` = `#FF9275`，`Color/Primary/Dark_01 状态-点击` = `#E56B4A`，`Color/Primary/Light_04 按钮禁用色` = `#FFD6CB`，`Color/Primary/Light_05 文字禁用色、按钮加载色` = `#FFC9BA`。

### 4.2 卡片 Card

卡片通常承载数据、配置、筛选结果和列表内容。默认使用白色背景，边框使用 `#E5E6EC` 或更弱的 `#F2F3F5`，页面背景使用 `#F7F8FA` 拉开层次。

普通业务卡片应保持轻质感，不用厚重投影。需要表达选中、指标强调或品牌高亮时，优先使用品牌浅色背景 `#FFF8F6`、品牌浅渐变，或功能色 01 阶背景。

推荐卡片层级：

| 类型 | 背景 | 边框/分割线 | 文字 |
|---|---|---|---|
| 默认卡片 | `#FFFFFF` | `#E5E6EC` | 标题 `#1D2129`，正文 `#4E5969` |
| 页面浅卡片 | `#F7F8FA` | `#F2F3F5` | 正文灰阶 |
| 品牌选中卡片 | `#FFF8F6` 或品牌浅渐变 | `#FFE4DC` / `#FFD6CB` | 标题可用 `#1D2129`，强调用 `#FF7752` |
| 数据浅色卡片 | 功能色 01 阶 | 功能色 02 阶 | 同色系 08 / 09 阶文字 |
| 指标重色卡片 | 固定功能渐变 | 无或同色弱边框 | 白色文字为主 |

### 4.3 数据卡与指标卡

数据卡是蝉圈圈组件库里功能色最重要的使用场景。浅色数据卡使用功能色 01 阶作为背景，02 阶作为同色卡片内分割线；选中或重色指标卡使用固定功能渐变。

指标卡状态建议：

- 默认/未选中：使用 Grey Gradient 或白底 + 灰色边框。
- 选中/高亮：根据指标含义使用 Red、Purple、Yellow、Blue、Green 五组固定渐变。
- 下降/成功/正向改善：优先绿色系。
- 上升风险、失败、异常：优先红色系。
- 警示但非失败：优先橙色系。
- 中性数据对比：优先蓝色、蔚蓝色、紫色。

### 4.4 导航与菜单

导航与侧边栏应保持清晰克制。选中态可使用品牌浅背景 `#FFF8F6`，选中文案或图标使用品牌主色 `#FF7752`。菜单 icon 可以使用品牌重色渐变 `color-gradient-primary-01`，这是品牌渐变在框架层组件里的典型用法。

默认导航文字使用 `#4E5969` 或 `#6B7785`，当前项使用 `#1D2129` 或品牌主色。导航区域背景通常为白色或浅灰 `#F7F8FA`，边界分割线使用 `#E5E6EC` / `#F2F3F5`。

### 4.5 表格 Table

表格属于高频业务组件，应优先保证可读性与扫描效率。表头背景使用 `#F7F8FA`，表格分割线使用 `#F2F3F5` 或 `#E5E6EC`。表头文字使用 `#86909C`，正文文字使用 `#1D2129` 或 `#4E5969`。

表格内 Tag 底色可使用 `#F2F3F5`。状态 Tag 可按功能色浅背景规则取值，例如成功用 `#EBF9F6`，错误用 `#FFEDE8`，警示用 `#FFF8E8`，信息用 `#F2F4FF` 或 `#EBF5FF`。

### 4.6 表单 Form

表单默认边框使用 `#E5E6EC`，输入文字使用 `#1D2129`，Placeholder 或辅助说明使用 `#86909C` / `#A9AEB8`。聚焦态优先使用品牌主色边框或品牌浅色外层反馈，避免临时蓝色焦点环。

表单错误态使用红色主色 `#F54B45` 与红色浅背景 `#FFEDE8`。警示态使用橙色主色 `#FF9A1D`。成功态使用绿色主色 `#00B489`。

### 4.7 标签、徽标与状态 Badge / Tag

默认 Tag 用浅灰底 `#F2F3F5` 和灰色正文。品牌强调 Tag 使用 `#FFF8F6` 背景、`#FF7752` 文字。New 标签可直接使用品牌主色或品牌浅底组合。

状态 Tag 推荐：

| 状态 | 背景 | 文字 |
|---|---|---|
| 成功 | `#EBF9F6` | `#006C52` |
| 失败/危险 | `#FFEDE8` | `#A1171B` |
| 警示 | `#FFF8E8` | `#A65508` |
| 信息 | `#F2F4FF` 或 `#EBF5FF` | `#344499` 或 `#014C99` |
| 品牌强调 | `#FFF8F6` | `#FF7752` |
| 中性 | `#F2F3F5` | `#4E5969` |

### 4.8 图表 Chart

图表颜色优先使用功能色主色：蓝 `#5771FF`、绿 `#00B489`、橙 `#FF9A1D`、红 `#F54B45`、紫 `#722ED1`、蔚蓝 `#027FFF`。品牌主色不应被过度用于多序列图表，避免和主交互语义混淆。

图表文字使用灰阶，坐标轴、网格线、辅助线使用 `#E5E6EC` 或 `#F2F3F5`。同色系深色文字可取功能色 08 / 09 阶。

### 4.9 宣发与 Banner

官网 Banner、品牌宣发等非系统页面可以使用 56、48、36pt 大标题，并允许自定义字色。此类场景可以使用品牌渐变和更大面积的品牌浅色背景，但仍应保持内容清晰，避免把固定功能渐变误用成品牌换肤渐变。

### 4.10 标题栏 Title Bar

标题栏规范来自 Figma 节点 `11261:6659` / `Title 标题栏` 组件集。该节点虽然归在 Typography / 排版页面下，但实际定义的是页面、卡片、弹窗、抽屉等标题栏组件结构，不应只当作字体表使用。

标题栏通用结构：

- 左侧为标题区域，可包含主标题、说明 icon、副标题或更新时间。
- 右侧为操作区域，可放按钮组合、单 icon、Tabs、文字+按钮、功能说明按钮、日期选择、分段控制器等。
- 背景默认白色，底部分割线使用 `#F2F3F5`。
- 标题栏左右 Padding 默认 `24px`，弹窗/抽屉/框架通用标题栏上下 Padding 默认 `16px`。
- 标题与副标题纵向间距默认 `4px`。
- 右侧按钮组合间距默认 `12px`，使用默认 32px 按钮。

标题栏类型：

| 类型 | 高度 | 圆角 | 主要结构 |
|---|---:|---|---|
| 框架_通用 | 76px | 顶部 12px | 左标题 + 可选副标题，右按钮组合 |
| 框架_Tabs | 64px | 顶部 12px | 左 Tabs，右按钮组合 |
| 框架_右侧Tab | 76px | 顶部 12px | 左标题，右侧 Tab / 操作 |
| 弹窗 | 76px | 顶部 16px | 左标题 + 副标题，右关闭 icon |
| 弹窗带搜索 | 64px | 顶部 16px | 左标题 / 搜索区域，右关闭 icon |
| 抽屉 | 76px | 无顶部圆角 | 左标题 + 副标题，右关闭 icon |
| 小卡 | 76px | 按卡片容器 | 小型卡片标题区域 |

标题文字规则：

| 元素 | 字体 | 字号 | 行高 | 颜色 | 间距 |
|---|---|---:|---:|---|---|
| 标题名称 | PingFang SC Semibold | 17px | 24px | `#1D2129` | 标题与说明 icon 间距 4px |
| 副标题/更新时间 | PingFang SC Regular | 12px | 16px | `#86909C` | 文案与说明 icon 间距 6px |
| 说明 icon | 组件原始 icon | 16px | - | 跟随次要信息色 | 使用组件原始资产 |
| 关闭 icon | 组件原始 icon | 24px | - | 深灰图标色 | Hover/Click 使用 28px HoverZone |

Tabs 标题栏规则：

- Tabs 标题栏整体高度 `64px`。
- Tabs 区域顶部 Padding `10px`，Tab 内容高度 `54px`。
- Tab 间距 `32px`，Tab 内 icon 与文字间距 `8px`。
- Tab 文案默认 14px / 22px；选中项可用 Medium，未选中项用 Regular。
- 选中下划线高度 `2px`，宽度约 `42px`，颜色 `#1D2129`，顶部圆角约 `1px`。
- 平台 Logo / 业务 icon 应使用组件库原始资产，不要用通用 icon 库替换。

### 4.11 分割线 Divider

分割线规范来自 Figma 节点 `11284:74853` / `Divider 分割线`。分割线用于区隔内容，视觉上应保持轻量，不应比卡片边框和表格线更抢眼。

基础规则：

- 默认颜色使用中性色 Grey 02：`#F2F3F5` / `color-gray-default-02`。
- 默认线宽为 1px。
- 分割线为 1px 线条规范，不作为独立图片资产定义。
- 分割线用于内容区隔时优先使用 Grey 02；需要更明确边界时才使用 Grey 03：`#E5E6EC`。
- 文本型分割线文字使用 Grey 08：`#4E5969`，字体使用 14px / Regular / 22px。

分割线类型：

| 类型 | 方向 | 线型 | 推荐规则 | 典型场景 |
|---|---|---|---|---|
| 直线拉通 | 横向 | 实线 | 宽度铺满容器，1px，`#F2F3F5` | 卡片内上下区隔、模块分区 |
| 虚线拉通 | 横向 | 虚线 | 宽度铺满容器，1px，`#F2F3F5`，使用 CSS dashed | 弱分区、可选内容区隔 |
| 左右间距 | 横向 | 实线 | 左右都保留容器内边距，不贴边 | 卡片内容区内分割 |
| 右侧拉通 | 横向 | 实线 | 左侧保留缩进，右侧拉到容器边缘 | 列表项、带左侧图标/标签内容 |
| 自定义左侧间距 | 横向 | 实线 | 左侧缩进按内容对齐线确定，右侧拉通 | 表单、列表、时间线等对齐场景 |
| 垂直分割线 | 纵向 | 实线 | 高度常用 14px，放在文本项之间 | 文案信息组、工具栏信息组 |
| 文字+直线 | 横向 | 实线 | 文案居中或指定位置，两侧线段与文字间距 16px | 分段提示、内容分界 |
| 文字+虚线 | 横向 | 虚线 | 同文字+直线，但线段使用虚线 | 更弱的分段提示 |
| 纯文字 | - | 无线 | 仅显示提示文字，颜色用 `#4E5969` | 列表底部“没有更多了”等状态 |

间距与排版：

- 文本项之间的垂直分割线高度常用 `14px`，和 14px 正文 / 22px 行高搭配。
- 垂直分割线两侧文本间距常用 `12px`。
- `文字+直线` 中，文字与两侧线段间距常用 `16px`，线段可按容器自适应。
- 示例中左右内边距常见为 `40px`，但真实页面应优先跟随所在卡片或列表的内容 Padding。
- 分割线文本说明使用 14px / Regular / 22px，颜色 `#4E5969`。

## 5. Layout Principles

当前资料没有提供完整栅格、间距、圆角或阴影 Token，因此本节为设计系统层面的布局归纳。部分组件级尺寸已从 Button、Title Bar 组件集中补充，具体组件优先看对应章节。

布局原则：

- 页面背景优先使用 `#F7F8FA`，内容区域使用白色卡片承载。
- 分区之间用留白、浅灰边框和 Grey 02 分割线建立层级，不依赖强阴影。
- 表格、筛选、卡片等业务密集区域保持信息密度，避免营销页式的大块装饰。
- 数据模块可以使用浅色功能背景帮助区分，但同屏不宜过多重色渐变。
- 文字层级按 24 / 20 / 18 / 16 / 14 / 12 / 10pt 递进，业务系统默认正文为 14pt。
- 组件圆角、间距、阴影若有组件实例定义，应优先遵循实例真实值；缺少实例值时，按钮可参考 6px 圆角，标题栏可参考 24px 左右 Padding、16px 上下 Padding、`#F2F3F5` 底部分割线。

推荐页面结构：

| 区域 | 建议 |
|---|---|
| 框架背景 | `#F7F8FA` |
| 主内容面 | 白色卡片或白色内容区 |
| 页面标题 | 24pt / Medium / `#1D2129` |
| 卡片标题 | 18pt 或 16pt / Medium / `#1D2129` |
| 正文 | 14pt / Regular / `#4E5969` 或 `#1D2129` |
| 说明文字 | 12pt / Regular / `#86909C` |
| 分割线 | 默认 `#F2F3F5` / 1px，需要更明确边界时用 `#E5E6EC` |

## 6. Token 使用与匹配规则

### 6.1 Token 优先级

使用蝉圈圈设计系统时请按以下优先级取值：

1. 具体设计稿或组件实例上已定义的变量、样式或组件属性。
2. 当前组件库规范中的 Token。
3. 同类组件的语义规则，例如按钮、卡片、Tag、表格。
4. 视觉近似值。

不要直接发明新颜色。若必须补值，优先从本规范相邻色阶取值，并在备注中标注为推导值。

### 6.2 颜色匹配规则

- 看到 `#FF7752` 或相近珊瑚橙，应匹配品牌主色 `color-primary-default`。
- 看到浅橙红背景，应优先检查是否为品牌浅色阶 `#FFF8F6`、`#FFF1EE`、`#FFE4DC`。
- 看到页面浅灰背景，应优先匹配 `#F7F8FA`。
- 看到边框或表格线，应优先匹配 `#E5E6EC` 或 `#F2F3F5`。
- 看到正文深灰，应优先匹配 `#1D2129`、`#4E5969`、`#86909C` 三档文字层级。
- 看到状态色时，按成功绿、警示橙、失败红、信息蓝的语义匹配，而不是只按色相相似匹配。

### 6.3 渐变匹配规则

- 品牌相关、可换肤、按钮或菜单 icon 渐变：用 `color-gradient-primary-01`。
- 品牌浅色卡片背景：用 `color-gradient-primary-02`。
- 指标卡选中态、重色状态：用固定功能渐变，不参与品牌换肤。
- 未选中指标卡：用 `color-gradient-grey-01`。

### 6.4 字体匹配规则

- 默认字体族：PingFang SC。
- 系统正文默认：14pt / Regular / 22pt。
- 卡片标题：18pt 或 16pt / Medium。
- 页面一级标题：24pt / Medium / 36pt。
- 12pt 与 10pt 只用于低重要度说明、时间戳、极小标签。
- 若具体项目使用 Web CSS px 单位，需要按项目换算规则统一处理；当前规范以 pt 记录，优先保持视觉层级一致。

## 7. Design System Summary

蝉圈圈设计组件库的核心特征：

- 整体风格为轻量业务系统，页面框架背景用 `#F7F8FA`，内容卡片多用白色和浅灰边框。
- 主交互统一使用品牌珊瑚橙 `#FF7752`，Hover 为 `#FF9275`，Click 为 `#E56B4A`，禁用为 `#FFD6CB`。
- 文字层级使用 PingFang SC，系统正文默认 14pt / Regular / 22pt，页面标题 24pt / Medium / 36pt，卡片标题 18pt 或 16pt / Medium。
- 主要文字用 `#1D2129`，正文/副标题用 `#4E5969`，辅助信息用 `#86909C`，禁用用 `#A9AEB8`。
- 按钮常用高度为 40 / 36 / 32 / 28 / 24px，矩形按钮与图标按钮默认圆角 6px，默认 32px 按钮横向 Padding 14px。
- 标题栏常用高度 76px，Tabs 标题栏 64px，左右 Padding 24px，上下 Padding 16px，底部分割线 `#F2F3F5`。
- 分割线默认使用 `#F2F3F5` / 1px，支持直线、虚线、左右间距、右侧拉通、自定义左侧间距、垂直分割线、文字+线和纯文字状态。
- 数据卡与图表使用功能色：蓝 `#5771FF`、绿 `#00B489`、橙 `#FF9A1D`、红 `#F54B45`、紫 `#722ED1`、蔚蓝 `#027FFF`。
- 指标卡重色选中态可用固定功能渐变；品牌相关渐变必须使用品牌渐变，不混用固定功能渐变。
